# v5 Change Log

v5 is a targeted update to v4. No MVP scope expansion.

Changes:
1. Refined Account model using classification + instrument_type.
2. Added optional instrument_id and instrument_label.
3. Documented stock, metal, bank and loan examples.
4. Explicitly deferred investment-specific quantity/valuation/tax mechanics.
5. Added database/application naming conventions.
6. Updated conceptual DBML with instrument fields.
7. Updated ADRs and open decisions accordingly.

Everything else from v4 remains unchanged.
