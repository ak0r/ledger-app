# Design Delta v1

Read Design.md for base references.

## Typography

UI / Primary:
Geist Sans

Financial / Tabular:
Geist Mono

Long-form editorial content:
Literata (optional, not used for core application UI)

Rules:

- UI uses Geist Sans by default.
- Financial numbers may use Geist Mono where tabular alignment improves scanning.
- Do not use monospace for all financial text.
- Avoid mixing multiple fonts within the same component without clear purpose.
- Typography hierarchy should come from size, weight, spacing, and semantic emphasis rather than excessive font variation.
